---

(1)如果 $a > 0$ ,那么 $\left| a\right|  = a$ ;

(2)如果 $a = 0$ ,那么 $\left| a\right|  = 0$ ；

(3)如果 $a < 0$ ,那么 $\left| a\right|  =  - a$ .
