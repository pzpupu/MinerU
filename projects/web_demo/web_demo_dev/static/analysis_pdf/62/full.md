## UNIQUELY DETERMINED ANALYTIC FUNCTIONS

Suppose that a function $f$ is analytic throughout a domain $D$ and $f\left( z\right)  = 0$ at each point $\mathrm{z}$ of a domain or line segment contained in $\mathrm{D}$ . Then $f\left( z\right)  \equiv  0$ in $D$ ; that is, $f\left( z\right)$ is identically equal to zero throughout $D$ .

## Remark:

- A function that is analytic in a domain $\mathrm{D}$ is uniquely determined over $\mathrm{D}$ by its values in a domain, or along a line segment, contained in D.

- Reflection Principle : Suppose that a function $f$ is analytic in some domain $\mathrm{D}$ which contains a segment of the $\mathrm{x}$ axis and whose lower half is the reflection of the upper half with respect to that axis Then $\overline{f\left( z\right) } = f\left( \bar{z}\right)$

Solution: Suppose $f\left( z\right)  = U + {iV}$

$$
\Rightarrow  \left| {f\left( z\right) }\right|  = \sqrt{{U}^{2} + {V}^{2}} \Rightarrow  {\left| f\left( z\right) \right| }^{p} = {\left( {U}^{2} + {V}^{2}\right) }^{p/2}... \tag{i}
$$

$$
\Rightarrow  \frac{\partial }{\partial x}{\left| f\left( z\right) \right| }^{p} = \frac{p}{2}{\left( {U}^{2} + {V}^{2}\right) }^{\frac{p}{2} - 1}\left( {{2U}{U}_{x} + {2V}{V}_{x}}\right)  = p{\left( {U}^{2} + {V}^{2}\right) }^{\frac{p - 2}{2}}\left( {U{U}_{x} + V{V}_{x}}\right)
$$

$$
\Rightarrow  \frac{\partial }{\partial x}{\left| f\left( z\right) \right| }^{p} = p{\left( {U}^{2} + {V}^{2}\right) }^{\frac{p - 2}{2}}\left( {U{U}_{x} + V{V}_{x}}\right)
$$

$$
\Rightarrow  \frac{{\partial }^{2}}{\partial {x}^{2}}{\left| f\left( z\right) \right| }^{p} = \frac{\partial }{\partial x}\left( {\frac{\partial }{\partial x}{\left| f\left( z\right) \right| }^{p}}\right)  = p\left( \frac{p - 2}{2}\right) {\left( {U}^{2} + {V}^{2}\right) }^{\frac{p - 2}{2} - 1}\left( {{2U}{U}_{x} + {2V}{V}_{x}}\right) \left( {U{U}_{x} + V{V}_{x}}\right)
$$

$$
+ p{\left( {U}^{2} + {V}^{2}\right) }^{\frac{p - 2}{2}}\left( {U{U}_{xx} + {U}_{x}{U}_{x} + V{V}_{xx} + {V}_{x}{V}_{x}}\right)

$$
\Rightarrow  \frac{{\partial }^{2}}{\partial {x}^{2}}{\left| f\left( z\right) \right| }^{p} = p\left( {p - 2}\right) {\left( {U}^{2} + {V}^{2}\right) }^{\frac{p - 4}{2}}{\left( U{U}_{x} + V{V}_{x}\right) }^{2}

$$
+ p{\left( {U}^{2} + {V}^{2}\right) }^{\frac{p - 2}{2}}\left( {U{U}_{xx} + {U}_{x}{}^{2} + V{V}_{xx} + {V}_{x}{}^{2}}\right)  \tag{ii}

Similarly

$$

$$

$$

## CHAPTER 3 ELEMENTARY FUNCTIONS

## THE EXPONENTIAL FUNCTION

We define here the exponential function ${\mathrm{e}}^{z}$ by writing ${\mathrm{e}}^{\mathrm{z}} = {\mathrm{e}}^{\mathrm{x}}{\mathrm{e}}^{\mathrm{i}\mathrm{y}}$ where $\left( {\mathrm{z} = \mathrm{x} + \mathrm{i}\mathrm{y}}\right)$ , Where Euler’s formula gives ${\mathrm{e}}^{\mathrm{i}y} = \cos y + \mathrm{i}\sin y$ and $y$ is to be taken in radians.

---

Remark:

																																			i. ${e}^{z} = \rho {e}^{i\varphi }$ where $\rho  = {e}^{x}$ and $\varphi  = y$

																										ii. $\left| {e}^{z}\right|  = {e}^{x}$

																						iii. $\arg \left( {e}^{z}\right)  = y + {2n\pi };n = 0, \pm  1, \pm  2,$

																						iv. ${e}^{{z}_{1}}{e}^{{z}_{2}} = {e}^{{z}_{1} + {z}_{2}}$ (addition theorem)

																							v. $\frac{{e}^{{z}_{1}}}{{e}^{{z}_{2}}} = {e}^{{z}_{1} - {z}_{2}}$

																		vi. ${e}^{z} \neq  0$ as ${e}^{x}$ is never zero.

								vii. ${e}^{0} = 1$

	viii. ${e}^{-z} = \frac{1}{{e}^{z}}$

																		ix. $\frac{d}{dz}{e}^{z} = {e}^{z}$ everywhere in the ’ $z$ ’ plane.

																							x. ${e}^{z + {2\pi i}} = {e}^{z}$

															xi. ${e}^{\pi i} =  - 1$ and ${e}^{2\pi i} = 1$

							xii. ${e}^{\left( {{2n} + 1}\right) {\pi i}} =  - 1;n = 0, \pm  1, \pm  2$ ,

xiii. ${e}^{z}$ converges absolutely.
