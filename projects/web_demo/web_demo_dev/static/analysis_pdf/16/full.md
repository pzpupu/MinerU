计算题.

21 (1) $\frac{{a}^{2} - 4}{{a}^{2} + {2a} - 8} \div  \left( {{a}^{2} - 4}\right)  \cdot  \frac{{a}^{2} - {4a} + 4}{a - 2}$ ; 解: 原式 $= \frac{{a}^{2} - 4}{\left( {a - 2}\right) \left( {a + 4}\right) } \cdot  \frac{1}{{a}^{2} - 4} \cdot  \frac{{\left( a - 2\right) }^{2}}{a - 2} = \frac{1}{a + 4}$ .

(2) $\frac{{x}^{2} - 1}{{x}^{2} - {4x} + 4} \div  \left( {x + 1}\right)  \cdot  \frac{{x}^{2} - {3x} + 2}{x - 1}$ .

化简求值.

23. $\left( {1 + \frac{1}{x - 1}}\right)  \div  \left( {1 - \frac{1}{x - 1}}\right)$ ,其中 $\mathrm{x} =  - \frac{1}{2}$ ;

解: 原式 $= \frac{x - 1 + 1}{x - 1} \div  \frac{x - 1 - 1}{x - 1} = \frac{x}{x - 1} \cdot  \frac{x - 1}{x - 2} = \frac{x}{x - 2}$ .

当 $\mathrm{x} =  - \frac{1}{2}$ 时,原式 $= \frac{1}{5}$ .

24. $\frac{1 - x}{{x}^{2} - 2 + x} \div  \left( {x - 2 + \frac{3}{x + 2}}\right)$ ,其中 $\mathrm{x} = \frac{1}{2}$ .

解: 原式 $= \frac{-\left( {x - 1}\right) }{\left( {x + 2}\right) \left( {x - 1}\right) } \div  \frac{\left( {x - 2}\right) \left( {x + 2}\right)  + 3}{x + 2} =  - \frac{1}{x + 2} \cdot  \frac{x + 2}{{x}^{2} - 1} =  - \frac{1}{{x}^{2} - 1}$ .

当 $\mathrm{x} = \frac{1}{2}$ 时,原式 $= \frac{4}{3}$ .

解方程.

解: 原式 $= \frac{{\left( x - 1\right) }^{2}}{\left( {x + 1}\right) \left( {x - 1}\right) } \cdot  \frac{x + 1}{2\left( {x - 1}\right) } = \frac{1}{2}$ .

由于化简后的代数中不含字母 $\mathrm{x}$ ,故不论 $\mathrm{x}$ 取任何值,所求的代数式的值始终不变. 所以当 $x = 3,5 - 2\sqrt{2},7 + \sqrt{3}$ 时,代数式的值都是 $\frac{1}{2}$ . 28. 对于试题: “先化简,再求值: $\frac{x - 3}{{x}^{2} - 1} - \frac{1}{1 - x}$ ,其中 $\mathrm{x} = 2$ . ”小亮写出了如下解答过程:

$\because \frac{x - 3}{{x}^{2} - 1} - \frac{1}{1 - x} = \frac{x - 3}{\left( {x - 1}\right) \left( {x + 1}\right) } - \frac{1}{x - 1}$①

$\frac{x - 3}{\left( {x - 1}\right) \left( {x + 1}\right) } - \frac{x + 1}{\left( {x - 1}\right) \left( {x + 1}\right) }$②

$\therefore$ 当 $x = 2$ 时,原式 $= 2 \times  2 - 2 = 2$ .④
